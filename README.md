**SaaS de agendamento multi-tenant** para negócios que atendem com hora marcada (salões,
barbearias, clínicas, consultórios, estúdios): cada negócio é um tenant com dados isolados,

como salão de beleza.
<br/>
*Multi-tenant scheduling SaaS for appointment-based businesses (salons, clinics, dental
offices, studios) — each business is a tenant with fully isolated data, team, services,
professionals, calendar and branding. Demo set up as a beauty salon.*

(checkout + acompanhamento do pedido) ou pelo WhatsApp com IA.
<br/>
*Multi-tenant delivery SaaS for restaurants — each one manages its own menu and orders;
customers order via a web menu (checkout + live tracking) or a WhatsApp AI agent.*

### 🏠 Projeto · Project — Controle de Aluguéis

**Sistema de controle de aluguéis em produção** para um proprietário de imóveis, desenhado
para um usuário idoso e não técnico usar no celular: "marcar como pago" num toque, semáforo
de pagamentos, IPTU por mês, reajuste anual, desfazer a última operação e histórico em calendário.
<br/>
*Rental control system in production for a property owner, designed for a senior, non-technical
user on a phone: one-tap "mark as paid", colour-coded payment status, monthly property tax,
annual adjustment, undo of the last operation and a calendar payment history.*
